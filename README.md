# Остров

React + Vite. Основной сайт: https://v1.travel.demo.krasnikoff.ru/

## Разработка

```sh
npm ci
npm run dev
```

`npm run build` создаёт `dist/`, `npm run preview` открывает сборку локально.

## Компоненты

`src/App.jsx` хранит параметры поиска, результаты и выбранный тур.
`src/components/` содержит Header, Hero, TripFinder, TravelerPicker,
TourResults, Journeys, Approach, ContactSection, Footer и общие иконки.
`src/hooks/useOceanVideo.js` управляет видео и освобождает обработчики при размонтировании.
`src/data/trip.js` содержит валидацию и форматирование параметров.
`src/data/tours.js` содержит демонстрационные программы, расчёт стоимости и фильтрацию.
Медиа находятся в `public/assets/`, источники — в `public/assets/SOURCES.md`.

## Каталог

Форма фильтрует программы по направлению, длительности и бюджету на всех.
Путешественники влияют на примерную стоимость. Город вылета и пожелания
передаются в заявку; наличие рейсов и мест сейчас не проверяется.
После выбора программы её название, цена и параметры поездки видны в заявке.
Программы, тарифы взрослых и детей — демонстрационные данные, не предложения
туроператора. Контактная форма не отправляет данные.

## Публикация

GitHub Actions собирает `main` и публикует `dist` в GitHub Pages.
Домен сохраняется через `public/CNAME`.
