# Остров

React + Vite + shadcn/ui. Сайт: https://v1.travel.demo.krasnikoff.ru/

## Разработка

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## Компоненты

- `src/components/ui/` — официальные исходники shadcn/ui, добавленные CLI (Radix, new-york, JavaScript).
- `components.json`, `jsconfig.json` — настройка shadcn и алиасов.
- `src/theme.css` — Tailwind 4 и цвета shadcn в палитре «Острова».
- `src/styles.css` — композиция и адаптивная вёрстка сайта.
- `TripFinder`, `DepartureRange`, `TravelerPicker`, `ChoiceField` — поиск.
- `TourResults` — отели, фильтры, сортировка и варианты предложений.
- `TourDetails` — панель тура с вкладками и переходом к заявке; загружается отдельно.
- `InquiryForm` — общая форма запроса с проверкой данных и деморезультатом.
- `src/data/` — демонстрационные данные и фильтрация; место для будущего адаптера поставщика.

Дополнительные shadcn-компоненты: `npx shadcn@latest add <name>`.
Медиа: `public/assets/`, источники: `public/assets/SOURCES.md`.

## Сценарий

1. Город вылета, страна с поиском по названию, зависимый курорт, диапазон возможных дат вылета, диапазон ночей, взрослые и дети с возрастом, бюджет.
2. Каталог отелей с минимальной ценой на всех. Фильтры звёзд и питания, сортировка цены/рейтинга.
3. Список предложений внутри отеля: конкретный вылет, ночи, номер, питание и цена.
4. Панель выбранного предложения: итоговые параметры, отель, перелёт, включённые услуги.
5. Имя и телефон, необязательные email и комментарий, согласие на связь. Возврат к деталям сохраняет заполненные поля.
6. Демонстрационный результат проверки заявки.

Как на функциональном референсе Avalon Tur, диапазон дат означает **возможные вылеты**, а не вылет и возвращение. День возвращения определяется конкретным предложением и его длительностью. Параметры поиска сохраняются при открытии и закрытии тура.

## Ограничения прототипа

Отели, рейтинг, звёзды, тарифы, даты и перелёт иллюстративны. Фото показывают направление, не конкретные отели. Даты демонстрационного инвентаря генерируются относительно текущего дня; цены не учитывают реальных тарифных правил. Нет API туроператора, проверки мест, отправки заявки, бронирования или оплаты. Контакты остаются в памяти страницы.

## Публикация

GitHub Actions собирает `main` и публикует `dist` в GitHub Pages.
Домен — через `public/CNAME`. Проверки описаны в [TESTING.md](TESTING.md).

Страны и курорты заданы в `src/data/destinations.js`: 15 демонстрационных стран. Выбор страны фильтрует каталог, изменение страны сбрасывает курорт; без страны доступен общий каталог. Для новых стран вместо нерелевантных фото используются заглушки. В реальном каталоге список должен приходить от поставщика туров.
