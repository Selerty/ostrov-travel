# Проверки сценария

```sh
npm ci
npm run build
npm run test:e2e
```

e2e поднимает production-сборку на http://127.0.0.1:4183.
Пять сценариев выполняются в desktop Chromium и при ширине 390px (10 проверок):

- отель → предложение → детали/перелёт → заявка → проверка данных → деморезультат;
- диапазон дат вылета независимо от ночей, включая вылет в один выбранный день;
- пустая выдача при ограниченном бюджете и индивидуальный запрос;
- ошибки диапазона вылета и незаполненного возраста ребёнка;
- фильтры класса/питания и сброс без потери поиска.

Полный сценарий также проверяет сохранение полей заявки при возврате к деталям и закрытие панели с восстановлением результатов.

Запуск с видимым браузером: `npm run test:e2e -- --headed`.
Трассировки: `.e2e/`. Модель и API-ключ для этих тестов не требуются.
В npm-скриптах используется локальный Node.js 24.
