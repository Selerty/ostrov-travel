# Проверки сайта с e2e

```sh
npm ci
npm run build
npm run test:e2e
```

Тесты запускаются на production-сборке. e2e поднимает сервер на
http://127.0.0.1:4183. Предпросмотр разработки на другом порту не затрагивается.

Четыре сценария выполняются на desktop Chromium и при ширине 390px:

- выбор тура из каталога и сохранение параметров в демозаявке;
- ошибки дат и возраста ребёнка, исправление и повторный поиск;
- направление из карточки путешествия;
- отсутствие программ в бюджете и переход к индивидуальной заявке.

Запуск с видимым браузером: `npm run test:e2e -- --headed`.
Результаты и трассировки ошибок сохраняются в `.e2e/`.
В npm-скриптах используется локальный Node.js 24.

Текущие проверки не требуют модели или API-ключа. Для `agent.act` нужно
выбрать провайдера и настроить `agents` в `e2e.config.ts`.
Справка: `npm run e2e -- guide setup`.

Документация: https://github.com/tester-army/e2e
